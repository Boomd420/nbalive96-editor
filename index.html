Sega Genesis / EA Sports ROM Utility

NBA Live 96 Editor & Roster Replica

A reverse-engineering and documentation project focused on replicating the classic 1996 Visual Basic executable editor for binary ROM customization and external stat synchronization.

Project Purpose

This repository provides a complete structural mapping and replica framework for the original NBA Live 96 Editor. It enables retro sports gaming enthusiasts to edit rosters, player attributes, biometrics, and team details directly in the binary ROM (.BIN) or via CSV stat imports.

Core Features

  • Manual Roster Editing: Modify individual player stats, jersey numbers, heights, weights, and appearance values.
  • CSV Export/Import Sync: Export full 470-player league datasets to CSV and re-inject modified external stats seamlessly.
  • 1-to-1 UI Alignment: Recreates the exact layout and controls of the original Visual Basic form forms (frmPlayer, frmTeam, frmRoster).

Binary Structure & Data Mapping

Every column in the repository's NBALIVE96OGROS.CSV corresponds directly to the internal 2MB binary ROM structure used by EA Sports in 1996:

  • JerseyNumber:1, Position:1, Height:1, Weight:1:+100 — Core biometric headers.
  • FieldGoal:1, ThreePoint:1, FreeThrow:1, Speed:1, Jump:1 — Ratings and player attributes (0–99 scale).
  • Minutes:2, Points:2, Assists:2, Rebounds:2 — 16-bit word values for career box score statistics.
  • LastName:ascii, FirstName:ascii — Variable-length null-terminated ASCII strings at player offsets.
