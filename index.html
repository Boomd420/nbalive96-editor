About NBA Live 96 Editor

Why would anyone bother coding an editor for NBA Live 96? Well, someone needed help hacking this classic Sega Genesis title. This web replica lets you modify player stats, jersey numbers, heights, weights, and ratings directly in your browser without dealing with desktop binaries or broken links.

Use Download CSV to export the current roster dataset, or upload your .bin ROM file to patch changes directly.
